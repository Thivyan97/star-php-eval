# Daily News MY: Laravel Practical Assessment

A small Malaysian news portal built with Laravel 13, SQLite, Blade and Bootstrap 5.

## Features

- `Category` and `Article` models with a one-to-many relationship (a Category has many Articles)
- Factories and a seeder (Faker): 6 categories, 20 curated sample articles, 6 Faker-generated articles and 2 drafts
- JSON endpoint `GET /api/articles` using an API Resource, with eager loading (`with('category')`) to prevent N+1 queries
- Article list page (Blade + Bootstrap 5) with a sticky header, real-time title search and category filter buttons
- Article detail page showing title, category, author, published date, reading time, body and related articles
- Extra article fields: `author` and `status` (drafts are hidden from the list, the API and the detail page)

## Requirements

- PHP 8.5+
- Composer 2.x
- Git

No Node.js is needed. Bootstrap is loaded from a CDN, so an internet connection is needed to see the styling.

## Setup

```bash
git clone https://github.com/Thivyan97/star-php-eval.git
cd star-php-eval
composer install
cp .env.example .env              # Windows PowerShell: copy .env.example .env
php artisan key:generate
touch database/database.sqlite    # Windows PowerShell: New-Item database/database.sqlite -ItemType File
php artisan migrate --seed
php artisan serve
```

Then open http://localhost:8000.

To reset the data at any time:

```bash
php artisan migrate:fresh --seed
```

## Design notes

- **Eager loading:** `Article::with('category')` is used in both the API controller and the web controller, so listing N articles takes 2 queries instead of N + 1.
- **Permalink routing:** `Article::getRouteKeyName()` returns `permalink`, so detail URLs are readable and use route model binding.
- **Query scope:** `Article::published()` keeps the draft filter in one place.
- **Accessors:** `Article::reading_time` and `Category::color` keep presentation logic out of the Blade views.
- **Search:** the title search and category filter run client-side in vanilla JavaScript, so results update instantly with no page reload. Pagination was intentionally left out because it would conflict with client-side filtering.
- **Sample data:** 20 articles are original, illustrative content written for this assessment, not real news reports. Additional articles are generated by `ArticleFactory` with Faker. Everything is seeded offline, so the app runs without any external API.
